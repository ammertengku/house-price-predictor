# House Price Predictor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a self-contained, beginner-friendly Jupyter Notebook that trains and evaluates a Malaysian-style synthetic house-price model and lets the learner predict a price in RM.

**Architecture:** `scripts/build_notebook.py` is the reproducible source for the notebook's Markdown and code cells; running it writes `House_Price_Predictor.ipynb`. The generated notebook contains the complete data generator, scikit-learn pipeline, evaluation, charts, validation, fallback function, and widget interface, so the notebook remains usable by itself. Pytest checks the notebook contract and core functions, while `nbclient` verifies clean top-to-bottom execution.

**Tech Stack:** Python 3.10+, Jupyter Notebook, NumPy, pandas, scikit-learn, Matplotlib, ipywidgets, nbformat, nbclient, pytest

**Spec:** `docs/superpowers/specs/2026-08-27-house-price-predictor-design.md`

## Global Constraints

- Generate exactly 2,000 fictional Malaysian-style homes by default with random seed `42`.
- Use prices in Malaysian ringgit and label every prediction as educational, not a real property valuation.
- Use an 80/20 train/test split with random seed `42`.
- Preprocess categorical features with `OneHotEncoder(handle_unknown="ignore")` inside a `ColumnTransformer` and `Pipeline`.
- Train `RandomForestRegressor(n_estimators=250, random_state=42, n_jobs=-1)`.
- Report MAE, RMSE, and R²; require controlled-data test R² of at least `0.75`.
- Provide both an `ipywidgets` interface and a plain `predict_house_price(...)` fallback.
- Keep the generated notebook self-contained; it must not require the build script at runtime.
- Do not download data, call an API, scrape a website, or imply professional valuation accuracy.

from pathlib import Path

import nbformat as nbf


ROOT = Path(__file__).resolve().parents[1]
DEFAULT_OUTPUT = ROOT / "House_Price_Predictor.ipynb"


def markdown(source: str):
    return nbf.v4.new_markdown_cell(source.strip())


def code(source: str, *tags: str):
    return nbf.v4.new_code_cell(source.strip(), metadata={"tags": list(tags)})


def build_notebook(output_path: Path = DEFAULT_OUTPUT) -> None:
    notebook = nbf.v4.new_notebook()
    notebook.metadata["kernelspec"] = {

        "name": "python3",

        code("""try:\n    import numpy as np\n    import pandas as pd\nexcept ModuleNotFoundError as error:\n    raise ModuleNotFoundError(\n        \"A required package is missing. Run %pip install numpy pandas scikit-learn matplotlib ipywidgets, then restart the kernel.\"\n    ) from error""", "core-test"),
        markdown("## 2. Create the Educational Dataset"),
        code("# Dataset implementation is added in Task 2.", "core-test"),
        markdown("## 3. Train the Model"),
        code("# Training implementation is added in Task 2.", "core-test"),

```python
def generate_housing_data(n_rows=2000, random_state=42):
    if not isinstance(n_rows, int) or n_rows < 100:
        raise ValueError("n_rows must be an integer of at least 100")
    rng = np.random.default_rng(random_state)
    location = rng.choice(["City Centre", "Suburban", "Small Town"], n_rows, p=[0.30, 0.48, 0.22])
    property_type = rng.choice(["Apartment", "Terrace", "Semi-D", "Bungalow"], n_rows, p=[0.36, 0.38, 0.18, 0.08])
    area = np.clip(rng.normal(1750, 800, n_rows), 450, 6000).round().astype(int)
    bedrooms = np.clip(np.rint(area / 550 + rng.normal(0.5, 0.8, n_rows)), 1, 8).astype(int)
    bathrooms = np.clip(np.rint(bedrooms * 0.65 + rng.normal(0.4, 0.6, n_rows)), 1, 7).astype(int)
    age = rng.integers(0, 61, n_rows)
    distance = np.round(rng.uniform(0.5, 70, n_rows), 1)
    parking = np.clip(rng.poisson(1.4, n_rows), 0, 5).astype(int)
    location_bonus = pd.Series(location).map({"City Centre": 260_000, "Suburban": 100_000, "Small Town": 0}).to_numpy()
    type_bonus = pd.Series(property_type).map({"Apartment": 0, "Terrace": 80_000, "Semi-D": 230_000, "Bungalow": 520_000}).to_numpy()
    price = (
        80_000 + area * 360 + bedrooms * 16_000 + bathrooms * 28_000
        + parking * 22_000 + location_bonus + type_bonus
        - age * 3_800 - distance * 4_200 + rng.normal(0, 45_000, n_rows)
    )
    return pd.DataFrame({
        "location_type": location,
        "property_type": property_type,
        "floor_area_sqft": area,
        "bedrooms": bedrooms,
        "bathrooms": bathrooms,
        "property_age_years": age,
        "distance_to_city_km": distance,
        "parking_spaces": parking,
        "price_rm": np.clip(price, 100_000, None).round(2),
    })
```

- [ ] **Step 6: Implement shared validation and the fallback function**

Define category constants and numeric bounds once. `validate_house_inputs(...)` returns a one-row dictionary after category membership, numeric type, finiteness, and inclusive-range checks. `predict_house_price(...)` passes that dictionary to `pd.DataFrame([validated])` and returns `float(model.predict(row)[0])`.

```python
LOCATION_TYPES = ("City Centre", "Suburban", "Small Town")
PROPERTY_TYPES = ("Apartment", "Terrace", "Semi-D", "Bungalow")
NUMERIC_BOUNDS = {
    "floor_area_sqft": (450, 6000), "bedrooms": (1, 8), "bathrooms": (1, 7),
    "property_age_years": (0, 60), "distance_to_city_km": (0.5, 70),
    "parking_spaces": (0, 5),
}


def validate_house_inputs(
    location_type, property_type, floor_area_sqft, bedrooms, bathrooms,
    property_age_years, distance_to_city_km, parking_spaces,
):
    if location_type not in LOCATION_TYPES:
        raise ValueError(f"location_type must be one of {LOCATION_TYPES}")
    if property_type not in PROPERTY_TYPES:
        raise ValueError(f"property_type must be one of {PROPERTY_TYPES}")
    numeric_values = {
        "floor_area_sqft": floor_area_sqft,
        "bedrooms": bedrooms,
        "bathrooms": bathrooms,
        "property_age_years": property_age_years,
        "distance_to_city_km": distance_to_city_km,
        "parking_spaces": parking_spaces,
    }
    for name, value in numeric_values.items():
        if isinstance(value, bool) or not isinstance(value, (int, float, np.integer, np.floating)):
            raise ValueError(f"{name} must be a number")
        low, high = NUMERIC_BOUNDS[name]
        if not np.isfinite(value) or not low <= value <= high:
            raise ValueError(f"{name} must be between {low} and {high}")
    return {
        "location_type": location_type,
        "property_type": property_type,
        **numeric_values,
    }


def predict_house_price(
    location_type, property_type, floor_area_sqft, bedrooms, bathrooms,
    property_age_years, distance_to_city_km, parking_spaces,
):
    validated = validate_house_inputs(
        location_type, property_type, floor_area_sqft, bedrooms, bathrooms,
        property_age_years, distance_to_city_km, parking_spaces,
    )
    return float(model.predict(pd.DataFrame([validated]))[0])
```
